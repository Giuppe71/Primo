# AI Duo Launcher

Una piccola app web statica che apre ChatGPT e Gemini contemporaneamente in nuove schede o finestre.

## Avvio locale

Apri direttamente `index.html` nel browser oppure avvia un server statico:

```bash
python3 -m http.server 8000
```

Poi visita <http://localhost:8000> e premi **Apri ChatGPT + Gemini**.

> Nota: alcuni browser bloccano l'apertura automatica di più schede. In quel caso abilita i popup per la pagina oppure usa il pannello di avvio per aprire i servizi singolarmente.
